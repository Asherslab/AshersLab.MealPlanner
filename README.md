# AshersLab.MealPlanner

A household meal planner: meals and ingredients, a rotating plan on a calendar, leftovers tracked as
serves, a shopping list split by store, and what it all costs — priced from imported Woolworths and
Costco receipts.

Blazor WebAssembly + MudBlazor, code-first gRPC, offline-first with SQLite in the browser. Runs as a
Home Assistant add-on or as a plain container.

Being built in vertical slices; only the scaffold exists so far. The design and the build order are in
[docs/](docs/README.md).
